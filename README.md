One image that sums up Thursday 19 November 2026, drawn as a newspaper
front page. The masthead carries the date, and six panels below it each
capture one of the day's biggest stories: the three-way Shenzhen summit,
the strikes across the Gulf, the call for aid access into Gaza, the global
launch of GTA VI, Voyager 1 reaching one light-day from Earth, and Hakeem
Jeffries' nomination as Speaker of the US House. Each panel pairs a simple
flat illustration with a single large headline label, so the whole day
reads at a glance.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only, no network) copies `entry.png`
into `$MAKEFUN_OUTPUT_DIR/entry.png`, creating the output directory first
if it does not exist yet. If `MAKEFUN_OUTPUT_DIR` is not set it defaults
to `./out/entry.png`.

## Files

- `entry.png` — the image itself (1024×1024 PNG).
- `main.ts` — the copy program described above.

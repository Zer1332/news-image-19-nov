A newspaper front page in a single 1024×1024 image that sums up the
world on Thursday 19 November 2026. The masthead carries the date in
large type — **THURSDAY 19 NOVEMBER 2026** — above the line
**THE WORLD IN ONE DAY**, and six illustrated panels below it tell the
day's six biggest stories.

## The six stories

1. **SHENZHEN SUMMIT** — Three leaders shake hands at a summit table
   in Shenzhen, with the flags of the United States, China, and Russia
   behind them.
2. **GULF STRIKES** — Warships and a tanker at sea at dusk, aircraft
   overhead, as strikes hit the Gulf and the Strait of Hormuz.
3. **GAZA AID CALL** — Aid trucks and tents in a flooded area, an aid
   worker handing a box to a resident.
4. **GTA VI LAUNCHES** — A neon Vice City-style night street with a
   game controller in the foreground as Grand Theft Auto VI launches.
5. **VOYAGER 1: ONE LIGHT-DAY** — The Voyager 1 spacecraft in deep
   space, a small Earth behind it, one light-day from home.
6. **JEFFRIES FOR SPEAKER** — The US House chamber with the Speaker's
   gavel on the desk as Hakeem Jeffries is put forward for Speaker.

## How to run

Requires Node.js 22 or later. No dependencies — the program uses the
Node standard library only.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` (the image next to `main.ts`) into the output
directory as `entry.png`. When `MAKEFUN_OUTPUT_DIR` is not set, the
output directory defaults to `/output`.
